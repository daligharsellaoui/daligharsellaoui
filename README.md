# Dali 👋

### Full-Stack Developer · Product Builder · Always Curious

</div>

<br>

I'm a **full-stack developer** who enjoys building things from scratch and figuring out how they should actually work along the way.

Most of what I do sits somewhere between **software, product, and design**. I like taking an idea, breaking down the problem behind it, building the system, and then spending way too much time making the UI feel right.

I work mostly with **Vue, TypeScript, Node.js, NestJS, PostgreSQL, and Docker** — and lately I've been spending more time exploring **AI, automation, and self-hosted infrastructure**.

I'm less interested in following whatever stack is trending and more interested in using the right tools to build something that is **fast, maintainable, and genuinely useful**.

Still learning, still experimenting, and still building.
